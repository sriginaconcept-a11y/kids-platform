# آفاق للسياحة والأسفار — قالب تجريبي

هذا المشروع هو نسخة تجريبية لموقع وكالة سياحية جزائرية، مصممة لعرض خدمات السفر إلى العملاء المحتملين بشكل احترافي وجذاب.

## ما الذي يتضمنه الموقع

- الصفحة الرئيسية مع هيكل تسويقي واضح
- قسم الرحلات والعروض مع فلترة حسب الوجهة ونوع الرحلة والميزانية
- صفحة تفاصيل كل رحلة
- صفحة عن الوكالة
- صفحة التواصل وطلب عرض
- دعم كامل للنسخة العربية والفرنسية
- واجهة متجاوبة ومناسبة للموبايل والكمبيوتر
- تنبيه واضح بأن هذا نموذج تجريبي وليس موقعًا حقيقيًا متصلًا بالنظام

## التقنية المستخدمة

- Flutter
- Dart
- Material 3
- url_launcher لفتح واتساب في نسخة تجريبية

## تشغيل المشروع

1. افتح المجلد الرئيسي للمشروع.
2. تأكد من تثبيت Flutter SDK على الجهاز.
3. نفّذ الأمر التالي:

```bash
flutter pub get
flutter run
```

## تخصيص اسم الوكالة والبيانات

توجد بيانات الهوية الأساسية في الملف التالي:

- `lib/config/site_config.dart`

يمكنك تعديل القيم التالية بسهولة:
- اسم الوكالة بالعربية والفرنسية
- البريد الإلكتروني
- رقم واتساب
- العنوان
- الألوان الأساسية

## تعديل العروض

العروض الحالية موجودة داخل ملف التطبيق الرئيسي في:

- `lib/main.dart`

توجد قائمة `demoTrips` وتحتوي على عروض تجريبية يمكن تعديلها أو استبدالها بسهولة.

## ملاحظات مهمة

- هذا نموذج تجريبي فقط.
- لا يتم إرسال أي طلب فعلي إلى جهة خارجية.
- جميع الرسائل والبيانات في هذا النموذج توضيحية فقط.
- إذا أردت ربط الموقع بنظام حقيقي، يمكن إضافة واجهة Backend لاحقًا.
